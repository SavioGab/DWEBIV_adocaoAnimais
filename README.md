# Adota Pet

## Descrição

O Adota Pet é um site desenvolvido para facilitar a adoção de animais. A plataforma permite cadastrar animais disponíveis para adoção e também encontrar animais para adotar.

## Descrição Objetiva

O projeto consiste no desenvolvimento de uma plataforma web voltada para a adoção de animais. O sistema terá cadastro de usuários, cadastro de animais, visualização dos animais disponíveis e solicitação de adoção.

## Objetivo

O objetivo do projeto é facilitar o processo de adoção de animais, permitindo que os usuários possam cadastrar animais para adoção, visualizar os animais disponíveis e realizar solicitações de adoção.

## Tecnologias

- HTML
- CSS
- JavaScript
- Python

## Framework

O projeto utiliza o framework Flask, seguindo a arquitetura MVC (Model-View-Controller).

## Banco de Dados

O banco de dados utilizado no projeto é o PostgreSQL.

## Pré-requisitos

Para executar o projeto, será necessário ter instalado:

- Python
- PostgreSQL
- Git
- Um navegador web
- Visual Studio Code ou outro editor de código
